Copper 是在 Mindustry 官方模组系统基础上扩展的模组加载器。它继承了原版 Java 模组的能力，并额外提供了一套与 Minecraft 同源的 **Mixin 框架**，允许模组在运行时对游戏代码和模组代码进行字节码级热修改，从而做到原版模组做不到的事情。
