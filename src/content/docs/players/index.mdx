本部分面向**玩家与服务器管理员**，介绍如何安装、更新、管理 Copper 模组，以及遇到问题时如何排查。

## 你需要知道的三件事

1. **Copper 不是独立游戏**。它是 Mindustry 的模组加载器：你仍然需要一个官方 Mindustry 游戏 Jar，通过 Copper 启动它。
2. **桌面版需要 Java 17 或更高版本**。如果你的机器上没有安装 Java 17+，请先安装（推荐 [Adoptium Temurin](https://adoptium.net/) 或你的发行版软件包管理器提供的 OpenJDK）。Android 端则通过[启动器 App](/players/android/)使用，不需要在设备上装 Java。
3. **模组管理在文件层面进行**。由 Copper 启动的 Mindustry **不支持**在游戏内导入、移除或启停模组——这些操作全部通过往模组文件夹里放入/删除 Jar 文件完成。这是有意为之的设计，详见[管理模组](/players/manage-mods/)。
